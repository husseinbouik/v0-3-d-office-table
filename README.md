# 3D Office Table — Interactive Viewer

A small interactive 3D viewer for an office table, built with React Three Fiber. Orbit around a single clean table model rendered in real time in the browser.

**Live demo:** https://v0-3-d-office-table.vercel.app

## Stack

- Next.js (App Router) + React + TypeScript
- Three.js via @react-three/fiber and @react-three/drei
- Tailwind CSS + Radix UI components

## Run locally

```bash
pnpm install
pnpm dev
```

Then open http://localhost:3000.

## Status

Early prototype / experiment — a bare model viewer without configuration options. For a full configurator-logic showcase, see [Zoning Studio](https://github.com/husseinbouik/zoning-studio).
